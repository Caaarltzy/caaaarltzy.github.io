QUICKEST WAY TO PUBLISH
Option 1 — Netlify Drop:
1. Extract this ZIP.
2. Go to Netlify Drop in your browser.
3. Drag the entire Carl_Adrian_Longasa_Portfolio_Website folder onto the upload area.
4. Netlify gives you a public URL.
5. You can later change the site name in Netlify settings.

Option 2 — GitHub Pages:
1. Create a GitHub repository.
2. Upload index.html and the assets folder.
3. Open repository Settings > Pages.
4. Choose Deploy from a branch, main branch, root folder.
5. Save and use the generated URL.

Option 3 — Google Sites:
Google Sites does not directly import this HTML as a full site.
You can use index.html as your exact layout/content reference, then recreate the sections in Google Sites.
Upload the Resume PDF and Portfolio PDF to Google Drive and link the buttons to those files.

IMPORTANT
Only the sanitized portfolio should be public. Do not publish original employer/client screenshots or confidential work files.
